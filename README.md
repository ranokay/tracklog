# Tracklog

A clean-room scrobbler droplet for [Droppy](https://getdroppy.app), bringing
Pano-Scrobbler-class listening history to the notch: Last.fm, ListenBrainz, Libre.fm and
Pleroma, with a local queue, a local history, metadata edits and blocks.

- **Droplet package:** [`tracklog/`](tracklog/) — SwiftPM, DroppyKit, SwiftUI.
- **Map:** [Scrobbler droplet: full Pano parity](https://github.com/ranokay/tracklog/issues/1).
- **Research:** `research/*` branches, one per question; no pull requests.
- **Licence:** MIT. Clean-room; no GPL code, strings or assets from Pano Scrobbler.

Inspired by [Pano Scrobbler](https://github.com/kawaiiDango/pano-scrobbler), not affiliated
with it.
