Stall cause: NSOpenPanel.runModal() blocks the harness's main thread for
as long as the panel is open. AX presses that enter the action return
-25204 (the action never completes), and AXOpen returns -25205 when the
modal session ends; AX reads and clicks on the harness window hang until
the panel closes. The earlier "sidebar stopped responding" was a panel
still open, not a harness bug.
