# AX readout — Play on existing surfaces

Fixtures: `TRACKLOG_DEMO_STATE=playing` for History and the strip;
`TRACKLOG_DEMO_STATE=playing TRACKLOG_HARNESS_CHARTS=normal
TRACKLOG_HARNESS_SECTION=charts` for Charts. Harness window 1320 × 940.

## Search button

- `AXButton` `Search and play`, id `magnifyingglass`, help `Search and play`,
  actions `AXPress`, in the takeover header beside the section picker. It is
  present on History and Charts; on Charts it sits to the left of the current
  connection picker.

## History row

- `AXButton` label `Heart of Glass, Blondie, Parallel Lines, 18:42`, value
  `delivered to ListenBrainz`, help `Shows this track's history`.
- Actions: `AXPress`, `AXShowMenu`, `AXScrollToVisible`, and a named
  `search and play` custom action.
- The row menu (right-click or the separate 28 × 28 `Actions for …` menu)
  contains `Search and play`, `Block` and `Copy metadata`, plus delivery and
  feedback sections where they apply.
- Track-history rows use the same `HistoryRow`; they are inert labelled
  elements with the same named `search and play` action and the same menu.

## Chart row

- `AXUnknown` label `Rank 1, Blondie, 42 plays`, actions:
  `AXScrollToVisible`, `AXShowMenu`, and a named `Search and play` custom
  action. The same label/action is on every ranked row.
- A right-click or `AXShowMenu` opens the row's context menu with
  `Search and play`.
- Query mapping: Artists use the artist name; Albums and Tracks use the
  artist and the row title (`artist album` / `artist title`). A local artist
  chart row with an empty subtitle falls back to the title.

## Now-playing strip

- The ellipsis is an `AXMenuButton` `More`. Opening it shows:
  - `AXMenuItem` `Search and play this track` (first item),
  - Pause, Edit this track, Block this track, Stop scrobbling and Settings.
- Screenshot: `docs/reports/issue-85/strip-overflow-menu.png`.

## Shelf overflow

- The shelf widget's `More` menu contains `Search and play…` as its first
  item, then Cancel this listen / Pause / Edit / Block / Stop scrobbling /
  Settings. It has no Play item; Play belongs to the strip.
- Screenshot: `docs/reports/issue-85/shelf-overflow-menu.png`.

## Summary

- Palette `Return` on a row uses `SearchPlayback.performPrimary`: play the
  encoded query when a template is set, otherwise open the row's Last.fm page.
  A row with no valid service page shows no `Open on Last.fm` custom action and
  reports why in the panel.
- The strip and History row Play uses `SearchPlayback.play`: a template opens
  the search URL; no template opens the Search settings page. A refusal is
  shown by `SearchRefusalBar` in the takeover, not written only to a log.
