Fixture: `TRACKLOG_DEMO_STATE=playing`. Opened `Actions for Heart of Glass` →
`Edit listen…`; the History takeover dismissed and the harness Settings pane
showed the contextual page.

`Remember as rule` on, and pressed Return for the page's default Save action.
The page closed and History returned with the corrected row.
