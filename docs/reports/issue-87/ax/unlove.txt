# AX readout — Unlove from a Loved row

Fixture: `TRACKLOG_DEMO_STATE=playing TRACKLOG_HARNESS_LOVED=normal TRACKLOG_HARNESS_SECTION=loved`.
Action: `AXPress` on `AXButton` `Unlove Example Track One`.

Before:

- `AXUnknown` `Example Track One, Example Artist, Example Album`
- `AXButton` `Unlove Example Track One`

After (the first surface re-reads the same state):

- The `Example Track One` row and its `Unlove Example Track One` button are
  gone from the list; the next row is `Example Track Two` with
  `Unlove Example Track Two`.
- The pinned strip keeps playing (`Heart of Glass`) and its own heart and
  overflow controls.
- This proves the row is removed only after the source connection confirms the
  action. The harness's feedback adapter returns success without a network.
