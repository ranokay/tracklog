- `AXStaticText` `Last.fm · listener`.

- `AXUnknown` `Example Track One, Example Artist, Example Album`

  `Removes the love on Last.fm and every connected service that supports love.`
- `AXUnknown` `Example Track Two, Example Artist, Example Album`
- `AXButton` `Unlove Example Track Two`, same help.
- … the same pair through `Example Track Eight`.

`<title>, <artist>, <album>`; the heart names the action and its fan-out.
